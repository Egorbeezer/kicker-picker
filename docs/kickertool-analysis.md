# Анализ функционала `app.kickertool.de` и сравнение с «кикер-пикер»

Дата аудита: 13–14 ноября 2026  
Изученная версия сервиса: `app.kickertool.de` v2.14.1 (Sep 3, 2026) и `live.kickertool.de`

---

## 1. Подробный разбор `app.kickertool.de` (v2.14.1)

### 1.1. Глобальная навигация, настройки и аккаунт
- **Home (`/tournaments`)**: список турниров аккаунта:
  - Сортировка: `BY DATE` | `BY NAME`.
  - Фильтр по режиму: `All modes`, `Swiss system`, `Rounds`, `Round Robin`, `Double Elimination`, `MonsterDYP`, `Last One Standing`, `Whist`, `Elimination`.
  - Поиск по названию.
  - Действия на карточке турнира: редактировать, вкл/выкл публикацию на Live-страницу (`public` / `public_off`), удалить, скачать/экспортировать файлом (`file_download`), открыть (`play_arrow`).
  - В шапке: `Import` (загрузка турнира из файла) и `NEW TOURNAMENT`.
- **Settings (выдвижная панель)**:
  - Язык интерфейса (9 языков): `English`, `Dutch`, `German`, `Danish`, `Chinese`, `French`, `Italian`, `Portuguese`, `Russian`.
- **Account**:
  - **Account Info (`/account/info`)**: username, email, смена пароля (`Current password`, `New password`, `Repeat new password`).
  - **Live Results (`/account/results-page`)**:
    - Персональная веб-страница `https://live.kickertool.de/<slug>`.
    - Настраиваемое название сайта (`Name of Website`).
    - Загрузка отдельных логотипов для светлой (`Light Theme`) и тёмной (`Dark Theme`) темы (`png`, `jpg`, `jpeg`, `webp`, `svg`, min height 70 px).
  - **Player Database (`/account/player-database`)**: интеграции с внешними базами федераций (`DTFB`, `STF`, `ATSA`).
- **Feedback**: модальное окно обратной связи.

### 1.2. Мастер создания турнира (`/new`)

#### Шаг 1. Выбор режима (8 режимов)
У каждого режима есть карточка описания (`...`) с применимыми типами участников, сценариями использования и кнопкой быстрого выбора:
1. **Swiss system** — швейцарская система (`Single`, `Teams`, `DYP`); есть тумблер расчёта `Dutch` / `Monrad`.
2. **Rounds** — произвольное число квалификационных раундов перед плей-офф (`Single`, `Teams`, `DYP`).
3. **Round Robin** — круговой турнир «каждый с каждым».
4. **Double Elimination** — олимпийка с верхней и нижней сетками (с выбыванием после двух поражений).
5. **MonsterDYP** *(Fair4All, Random DYP)* — динамическая смена партнёра каждый раунд, личный рейтинг.
6. **Last One Standing** — у каждого игрока `1–10` жизней (по умолчанию `3`); за поражение отнимается жизнь, при позднем входе подставляется текущее среднее число жизней.
7. **Whist** — раундовая ротация партнёров по правилам виста.
8. **Elimination** — классическая одиночная олимпийская сетка (Single KO).

#### Шаг 2. Настройки турнира (зависят от режима)
- **Live Results Page**: тумблер `Publish Tournament` (публикация на `live.kickertool.de/<slug>`).
- **Специфичные опции режима**:
  - *Swiss*: `Use table position in Swiss system calculation` (`OFF` = Dutch, `ON` = Monrad).
  - *Last One Standing*: `Number of Lives` (`1–10`, default `3`).
- **Tables**: `Number of Tables` (`1–200`).
- **Goals**:
  - `Quick Entry` (фиксация только победителя/ничьей без счёта голов) или `Goals to Win` (`1–100`, по умолчанию `7`).
  - Чекбокс `Draw` (разрешить ничьи; выключен для Elimination и Double Elimination).
- **Winning Sets**: `1–10` сетов до победы в матче (по умолчанию `1`).
- **Standings Points** (для квалификационных/очковых режимов):
  - `Points for Win` (по умолчанию `2`) и `Points for Draw` (по умолчанию `1`).
  - Тумблер `Points for scarce matches` (упорные матчи): разница голов (default `1`), очки победителю в упорном матче (default `2`), очки проигравшему в упорном матче (default `1`).
- **Bye**: тумблер `Rate Byes` (засчитывать вынужденный пропуск раунда как победу с половинным счётом условного соперника).
- **Disciplines** (до 10 дисциплин в матче): у каждой дисциплины своё `Name`, `Winning Sets` (`1–10`) и `Goals to Win` (`1–100`).

#### Шаг 3. Добавление участников
- **Import participants**: массовая вставка списка имён (через запятую, точку с запятой или с новой строки), поддержка `#<ID> <Name>` для связки с базой федерации.
- **Shuffle Participants**: перемешать список.
- **Выбор формата участников** (для Swiss / Rounds / Round Robin / Elimination / Double Elimination):
  - `Team Names` (готовые команды, порядок задаёт начальный посев),
  - `Single Players` (одиночки),
  - `Doubles` (`Player 1` + `Player 2` на команду),
  - `Draw Your Partner` (DYP) с чекбоксом `Set Players` — добавляет переключатель роли/уровня `A | — | B`, чтобы пары формировались `A + B`.
- Для **MonsterDYP** и **Last One Standing**: сразу список индивидуальных игроков (`Mix every round`).

### 1.3. Экран активного / завершённого турнира
- **Боковые панели турнира**:
  - **Settings**: изменение названия, `Quick Entry`, `Goals to Win`, `Draw`, `Points for Win`, `Points for Draw`, языка.
  - **Participants**: дозаявка по ходу турнира (`Add Participant`, в *Last One Standing* с выбором стартовых жизней `Lives (Ø ...)`), отметка отсутствия/возврата (`mark absent` / `mark present`), переименование (`Rename`).
  - **Tables (`Edit Tables`)**: добавление столов (`ADD TABLE`) и индивидуальное вкл/выкл каждого конкретного стола по номеру.
  - **External Display (`/display/#/<id>`)**: внешний экран для ТВ/проектора с выбором вида (`LOGO`, `Qualifying`, `Elimination`, `Tree`) и темы (`Dark` / `Light`).
- **Qualifying View (`/tournament/<id>`)**:
  - Тулбар: `Print`, переключение списка/таблицы, `Fullscreen`, переход к плей-офф (`>`), `START ELIMINATION`.
  - Split-pane с ползунком ширины (`0–100`, default `50`): слева раунды и матчи, справа таблица.
  - В раундах: поиск/фильтр матчей, кнопка `Delete Round` для последнего раунда, `NEW ROUND`, `SHOW RESULT`.
  - Ввод счёта: inline-клавиатура (`0–8` / `0–11` + `+`), поддержка нескольких сетов рядом, `CANCEL` / `CONFIRM`.
  - Действия по клику на бейдж стола в матче: `Deactivate`, `Reset Result`, ручной выбор стола (`Table` dropdown: `---` или номер стола).
  - **Настройка таблицы (`Table Columns`)**: 16 колонок с drag-сортировкой приоритета:
    1. `Matches won`
    2. `Average points (fair)` (`ØP*` со звёздочкой при недоборе игр)
    3. `Goal difference`
    4. `Match count`
    5. `Team name`
    6. `Average Buchholz Score 1`
    7. `Average points`
    8. `Points`
    9. `Average Buchholz Score 2`
    10. `Buchholz Score 1`
    11. `Buchholz Score 2`
    12. `Sonneborn-Berger`
    13. `Matches draw`
    14. `Matches lost`
    15. `Goals in`
    16. `Goals`
  - **Live Stats под таблицей**: `average play time`, `played matches` / `open matches`, `play time` / `expected end` + `% completed`, `participants`.
- **Elimination / KO View (`/tournament/<id>/ko`)**:
  - Переключение `Tree view` (визуальное дерево сетки с `Zoom` `33–100`) ↔ `List view`, `Print`, `Fullscreen`, поиск матчей.
- **Final Result / Podium (`/tournament/<id>/result`)**:
  - Итоговый рейтинг мест (`1., 2., 3., ...`) со вкладками этапов (`Qualifying`, `Сетка 1`) и печатью.
- **Public Live Results (`https://live.kickertool.de/<slug>`)**:
  - Публичный веб-портал с переключением `Light / Dark`, вкладками `STANDINGS`, `QUALIFYING`, `ELIMINATION` и фильтром стадий.

### 1.4. Чего нет в самом `app.kickertool.de` (v2.14.1)
- Нет встроенных модулей **Лиг**, **Сезонов** и **Клубов**.
- Нет внутренней системы **Elo / скилл-рейтинга** (только внешние ID федераций и ручные корзины `A`/`B`).
- Нет таймера матча, звуковых уведомлений, монетки/жеребьёвки стороны, QR-генератора и самоввода/подтверждения счёта игроками.

## 2. Сравнение: чего сейчас нет в «кикер-пикер»

На текущий момент в `kicker-picker` реализован **MonsterDYP** (автожеребьёвка 2×2 с минимизацией повторов, честные bye, автораунды, отложенный плей-офф Топ-4/8/16/32 + матч за 3-е место, сеты `Best of 1/3/5` в плей-офф, графическое дерево сетки плей-офф, настраиваемая таблица по 5 колонкам и выгрузка полной таблицы в PNG, Telegram-аватарки, 3D-монетка рубля, подтверждение счёта в Mini App и инлайн-кнопками в боте, тёмная/светлая тема, приглашения через Telegram-ссылку).

### Недостающий функционал по группам

1. **Режимы турниров и форматы команд**
   - Режимы: `Last One Standing`, `Swiss system` (Dutch / Monrad), `Round Robin`, `Whist`, `Elimination` сразу без квалификации, `Double Elimination` (верхняя + нижняя сетка).
   - Форматы участников: `1×1 (Single Players)`, постоянные пары/команды (`Doubles` / `Team Names`), классический DYP с корзинами `A / B` (`Set Players`).

2. **Управление матчами, раундами и столами**
   - Удаление / откат последнего раунда (`Delete Round`).
   - Перенос конкретного матча на другой стол вручную, сброс счёта и деактивация отдельного матча.
   - Точечное включение/отключение конкретных столов по номеру (а не только общее число `tablesCount`), расширение лимита столов (`>20`) и голов (`>21`).

3. **Гибкие правила подсчёта**
   - `Quick Entry` (только победитель без счёта голов).
   - Поддержка ничьих (`Draw`) и настраиваемых очков (за победу, ничью, упорный матч `scarce match`, учёт пропусков `Rate Byes`).
   - Несколько сетов в квалификации и составные матчи из нескольких дисциплин (`Disciplines`).

4. **Участники и списки турниров**
   - Массовый импорт игроков текстом/списком + перемешивание.
   - Переименование уже добавленных игроков.
   - Отдельный экран списка турниров с поиском, сортировкой и фильтром (сейчас только компактный dropdown в шапке).

5. **Статистика, аналитика и итоги**
   - **Отдельный экран итогов / подиума** с полной классификацией всех мест по этапам (сейчас отображается подиум победителя в сетке плей-офф и финальный экран).
   - **Тайминги турнира**: среднее время матча, прошедшее время, прогноз времени окончания (`expected end`) и `% завершённости`.
   - Дополнительные метрики таблицы (например, `ØP*` — fair average points со звёздочкой при недоборе игр, поражения, ничьи, забитые/пропущенные мячи).
   - Масштабирование (`Zoom`) в дереве сетки плей-офф.

6. **Публичность, ТВ-экран и перенос**
   - Внешний экран для ТВ/проектора (`External Display`) и публичная веб-ссылка на лайв-результаты без входа в Telegram.
   - Экспорт / импорт турнира файлом и печать протоколов/сетки.
   - Мультиязычность (при необходимости выхода за пределы РФ).

## 3. Преимущества «кикер-пикер» (чего нет в Kickertool)
- Самоввод и взаимное подтверждение/оспаривание счёта игроками (в приложении и инлайн-кнопками прямо в Telegram-боте, плюс напоминания).
- Автораунды (`autoRounds`) и отложенный старт плей-офф (`pendingPlayoff`) после закрытия текущих матчей.
- Персональные Telegram-уведомления о старте раунда и подтягивание аватарок игроков.
- 3D-монетка (российский рубль) для розыгрыша подачи/стороны.
- Встроенный переключатель тёмной и светлой темы в самом приложении.
