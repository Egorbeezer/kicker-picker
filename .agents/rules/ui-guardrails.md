# UI-гайдлайны (React + Telegram Mini App)

1. **Числовые инпуты с границами (`min`/`max`)**: не делать жёсткий `clamp` в `onChange` — хранить локальный строковый черновик при фокусе (разрешать очистку поля) и нормализовать/ограничивать значение только в `onBlur` или по `Enter`.
2. **Многошаговые формы и визарды**: кнопке финальной отправки (`type="submit"`) на последнем шаге всегда задавать уникальный `key`, отличный от кнопки «Далее» на предыдущих шагах, чтобы React не переиспользовал DOM-узел и не происходил случайный submit.
3. **Светлая и тёмная темы Telegram Mini App**: для всех текстовых полей ввода явно задавать `caret-color` и проверять видимость курсора и контрастность текста как в светлой, так и в тёмной теме.
4. **Деструктивные действия**: удаление участников, турниров и любых пользовательских данных выполнять только через подтверждение (модальное окно / явный confirm), не в один клик.
